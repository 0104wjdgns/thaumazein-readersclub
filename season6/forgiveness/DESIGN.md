# 리더스클럽 웹 발제문 — 디자인 시스템 (월간 공통 템플릿)

> 인쇄용 「타우마제인 리더스클럽 발제문 디자인MD」의 철학(여백은 사유의 공간 · 챕터 색상 감성 코딩 · 1인칭 '사유 초대장')을 웹으로 옮긴 규격.
> 참고: **Oura식 에디토리얼**(크림 종이, 넉넉한 여백, 얇은 세리프, 단 하나의 결정적 액센트) + **Runway식 시네마틱 다크 커버**(어두운 표지 → 밝은 읽기 띠의 교차). 원칙만 빌리고, 두 브랜드의 로고·색·카피는 쓰지 않는다.

## 1. 원칙
1. **종이 위의 생각.** 읽기 화면은 늘 크림 종이(#f6f0e6). 장식보다 여백.
2. **표지만 극장처럼.** 표지는 테마 메인색의 시네마틱 다크. 읽기가 시작되면 종이로 내려온다.
3. **색은 한 가지 감정만.** 주제마다 바뀌는 것은 `--theme-main`, `--theme-sub` 두 개뿐.
4. **움직임은 장면이 바뀔 때만.** 쓰는 자리는 고요하게.
5. **1인칭 초대장.** "~해 주세요" 존댓말, 정답 없는 질문, 마지막은 항상 `+N.`

## 2. 고정 토큰 (매달 바꾸지 않음) — `assets/style.css :root`
| 분류 | 토큰 |
|---|---|
| 종이/잉크 | `--paper #f6f0e6` · `--paper-2` · `--surface #fffcf7`(카드/입력칸) · `--ink #1d1b19` · `--ink-soft` · `--ink-faint` · `--hairline #e1d9cc` |
| 서체 | 제목·질문·인용 **Noto Serif KR**(300–500), 본문·UI **Noto Sans KR**. 본문 17px/1.85, 질문 22–26px/1.6 |
| 간격 | `--s1`~`--s9` (4·8·12·16·24·32·48·64·96px). 섹션 사이는 최소 `--s7` |
| 모서리/선 | 카드 16px, 버튼 pill(999px), 구분선 1px hairline. 그림자는 카드 1단계만 아주 옅게 |
| 모션 | `--ease-out cubic-bezier(.2,.7,.2,1)`, 짧음 240ms / 장면 600–900ms |

## 3. 주제별로 바꾸는 것 (딱 두 색)
```css
--theme-main: #16213e;   /* 표지 배경, 제목 밑줄, 진행바, 주 버튼 */
--theme-sub:  #e9a07a;   /* 표지 강조어, 인용부호, 완료 점, 새벽빛 */
```
- `--cover-bg`(표지 그라디언트)와 `--theme-tint`(옅은 배경 틴트)는 위 두 색에서 `color-mix()`로 **자동 파생**. 따로 정하지 않는다.
- **테마색이 허용되는 곳은 5군데뿐:** ① 표지 배경 ② 제목 밑줄(rule) ③ 진행바 ④ 버튼 ⑤ 강조(표지 핵심어, 인용부호, 완료 점).
- 본문 텍스트·입력칸·카드 배경에는 쓰지 않는다(항상 종이/잉크).
- 대비: 버튼 글자는 흰색, `--theme-main`은 종이 위에서 WCAG AA(4.5:1) 이상인 어두운 색으로 고른다.

### 팔레트 예시
| 달 | 주제 | main | sub | 느낌 |
|---|---|---|---|---|
| 9월 | 사랑과 이기심 | `#3d0f1c` 와인 | `#c9a35c` 골드 | 촛불 켠 저녁 |
| 10월(예시) | 가족 | `#4f5a2e` 올리브 | `#c08a3e` 오커 | 오래된 부엌, 가을 볕 |
| 11월 | 관계 속 감정의 해소와 용서 | `#16213e` 딥 네이비 | `#e9a07a` 새벽 살구 | 긴 밤 끝의 새벽 |

## 4. 화면 구조
```
표지(핵심 질문) → 이름 선택 → [질문 1 → 자료 1] → [질문 2 → 자료 2] … → [n. → 자료 n] → 완료(+N.)
```
- **각 질문 뒤에는 그 질문 전용 자료 페이지가 하나씩 붙는다** (주제의 질문 수만큼 5~6회 반복). 답을 먼저 쓰고 → 자료를 연다: 남의 문장보다 내 생각이 먼저.
- **질문 화면:** `1_라벨`(세리프 큰 숫자 + 밑줄) → 배경 글(산문) → hairline → `Q.` 질문(세리프) → 입력칸. 마지막 질문 번호는 `n.`
- **자료 화면(인용 카드 1장):** 살구색 인용부호 → 격언(세리프, 크게, 한국어) → 원어 한 줄(작게, 흐리게) → hairline → 저자(굵게) + 작품·장절 → 필요 시 한 줄 주석. 자료가 아직 없으면 `material.pending: true` → '자료 준비 중' 배지.
- **완료:** 7개의 점(제출 인원), 마무리 글, **`+N.` 고정 문구(삭제 금지)**:
  > +N. 토론과 직접 이어지지 않아도 좋아요. 심오하지 않아도 좋아요. 이번 토론 이후 내 안에 남은 '오직 나만의 이어지는 질문'은 무엇인가요?

## 5. 모션 (5가지 시그니처)
| # | 장면 | 동작 |
|---|---|---|
| 1 | 표지 | 잡지 표지처럼 마스트헤드 → 제목 → 밑줄(그려짐) → 핵심 질문 한 줄씩 떠오름. 스크롤/스와이프/탭/키로 이름 선택으로 |
| 2 | 질문 진입 | 섹션 라벨이 화면 중앙에 크게 떴다가 제자리로 줄어 안착(FLIP) → 질문이 단어 단위로 드러남 → 입력칸 페이드인 |
| 3 | 자료 | 접힌 종이가 펴지듯 카드가 위에서 아래로 펼쳐짐(rotateX + 접힘선 그림자) |
| 4 | 진행 | 진행할수록 배경이 밤(테마 메인 틴트) → 새벽(테마 서브 빛) → 크림으로 밝아짐 (`--p` 0→1) |
| 5 | 완료 | 7개의 점이 제출 인원만큼 차례로 켜짐 |

규칙
- **움직이는 건 장면 전환 때만.** 입력칸·버튼·글자 수 표시는 절대 흔들리지 않는다(포커스 링만 변화).
- 한 번 본 화면으로 돌아오면 애니메이션 없이 즉시 표시.
- `prefers-reduced-motion: reduce` → 모든 애니메이션 제거, 즉시 최종 상태. 배경 변화도 전환 없이 적용.
- transform/opacity만 애니메이트(레이아웃 흔들림 없음).

## 6. 입력·저장
- 입력칸: 종이보다 한 톤 밝은 `--surface`, hairline 테두리, 최소 높이 약 5줄(9.5rem), 내용에 따라 자동으로 늘어남(손잡이 없음). 플레이스홀더 "떠오르는 생각을 자유롭게 적어 주세요."
- 자동 저장(이름별 localStorage `rc-<ROUND>-<이름>`), "자동 저장됨 · 시:분" + 글자 수를 작게.
- 모바일 우선(390px 기준), 데스크톱은 본문 폭 36rem(576px) 중앙 칼럼, 표지는 전체 화면.

## 7. 매달 하는 일 (체크리스트)
1. `assets/topic.js` 교체: round, monthLabel, title, theme(두 색), coreQuestionLines, intro, names, questions[](label·background·q·material), closing. `plusN`은 그대로.
2. `config.js`의 `ROUND`를 같은 값(YYYY-MM)으로.
3. 자료 문장은 출처를 확인하고 `QUOTES.md`에 URL과 함께 기록.
4. 로컬에서 열어 표지·질문·자료·완료를 휴대폰 폭으로 확인 → 배포.
